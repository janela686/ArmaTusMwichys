# mwichys.com

Este repo es la página web de mwichys (GitHub Pages, dominio en `CNAME`).

Si trabajas aquí como el **Agente Web**, lee y sigue `_agente/AGENTE.md`. Los cambios del drop (cupos vendidos, agotado, fechas, nuevo drop) se hacen solo con `python3 _agente/drop.py`.

El repo es público: no guardes aquí datos de clientas ni claves.
